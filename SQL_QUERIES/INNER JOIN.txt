***************************************************************** INNER JOIN ******************************************************************************
-It is used to obtain only matching records
-Where we are using inner join we should write join condition.

Syntax
-------
ORACLE
=======
SELECT COLUMN_NAME
FROM T_N1,T_N2
WHERE <JOIN_CONDITION>;

ANSI
=====
SELECT COLUMN_NAME
FROM T_N1 INNER JOIN T_N2
ON <JOIN_CONDITION>;

Q1) NAME OF THE EMPLOYEE AND HIS LOCATION OF ALL THE EMPLOYEES
--->

=======

FROM EMP,DEPT
WHERE EMP.DEPTNO=DEPT.DEPTNO;

ANSI
=====
SELECT ENAME, LOC
FROM EMP INNER JOIN DEPT
ON EMP.DEPTNO=DEPT.DEPTNO;
