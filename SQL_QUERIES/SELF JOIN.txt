
************************************************************************** SELF JOIN  ***********************************************************************************
-Joining the same two tables is known as SELF JOIN.
           OR
-Joining a table by itself is known as self join.


When do we use self Join?
--->
Whenever the data to be selected in the same table but present in the different records we use self join.

Syntax
-------

ORACLE
======
SELECT COLUMN_NAME
FROM TABLE1 T1 , TABLE2 T2 
WHERE <JOIN_CONDITION>;

ANSI
=====
SELECT COLUMN_NAME
FROM TABLE1 T1 JOIN TABLE2 T2 
ON <JOIN_CONDITION>;

********************************************************************* ASSIGNMENT ON SELF JOIN ****************************************************************************

Q1) WAQTD NAME OF THE EMPLOYEE AND HIS MANAGER'S NAME IF EMPLOYEE IS WORKING AS CLERK.
--->
ORACLE
======
SELECT E1.ENAME, E2.ENAME
FROM EMP E1, EMP E2
WHERE E1.MGR=E2.EMPNO AND E1.JOB='CLERK';

ANSI
=====
SELECT E1.ENAME, E2.ENAME
FROM EMP E1 JOIN EMP E2
ON E1.MGR=E2.EMPNO
WHERE E1.JOB='CLERK';


Q2) WAQTD NAME OF THE EMPLOYEE AND MANAGER'S DESIGNATION IF MANAGER WORKS IN DEPT 10 OR 20.
--->
ORACLE
======

FROM EMP E1, EMP E2
WHERE E1.MGR=E2.EMPNO AND E2.DEPTNO IN (10,20);

ANSI
=====
SELECT E1.ENAME, E2.JOB
FROM EMP E1 JOIN EMP E2
ON E1.MGR=E2.EMPNO
WHERE E2.DEPTNO IN (10,20);
